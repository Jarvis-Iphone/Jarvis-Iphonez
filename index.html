KI-Verbindung (optional)

Standardmäßig funktioniert JARVIS offline mit lokalen Befehlen. Für echte KI brauchst du einen eigenen HTTPS-Server mit einem kompatiblen Chat-Endpunkt. Niemals einen geheimen OpenAI-API-Schlüssel in diese Web-App eingeben.

Erwartet POST JSON {message: "..."} und Antwort JSON {reply: "..."}. Der Server muss CORS für deine Web-App erlauben und den Zugriff authentifizieren. Ein öffentlich ungeschützter KI-Endpunkt ist nicht sicher.

Installieren: Website über HTTPS öffnen → Safari Teilen → Zum Home-Bildschirm. iOS kann Hintergrundfunktionen und automatische Wiedergabe einschränken.
